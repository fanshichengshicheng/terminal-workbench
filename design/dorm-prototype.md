# 宿舍 Spine 原型

## 任务

在现有个人工程工作台中验证一条完整的 Spine 角色链路：载入公开示例角色、播放动作、点击地面移动，并让角色自然融入空置工业宿舍。当前原型不处理家具、商店、装修编辑器和用户资源包导入。

## Flow graph

```text
07 宠物 / DORM
  ├─ 进入模块 → Spine 资源加载 → 角色待机
  ├─ 点击地面 → 行走到目标 → 恢复待机
  ├─ 点击角色附近 → 播放互动动作 → 恢复待机
  ├─ 动作浮层 → 待机 / 巡逻 / 跳跃 / 特殊动作
  └─ 加载失败 → 显示诊断 → 重新加载
```

## 视觉约束

- 使用冷灰金属墙板、空旷深色地面、冷白顶灯与低饱和状态色。
- 左侧工程轴新增第七个真实栏目，不增加第二套导航。
- 宿舍采用正视横向 2.5D 舱室：顶部结构、墙板分缝、明装线缆、低位管线与右侧舱门构成空间记忆点。
- 当前保持空置，不放置休息舱、终端、娱乐区或训练设施。
- 不复制或内置游戏素材，只在原创 CSS 场景中还原空间组织与工业氛围。

## Prototype boundary

- Spine Runtime：`@esotericsoftware/spine-pixi-v8 4.2.x`。
- 示例资源：Spine 官方 Spineboy 4.2，保留原始许可证，仅作本地非商业原型验证。
- 数据：纯前端状态；未来角色包、装修和经济系统接入点保留在 manifest 与 UI 中。
