# 开屏动效规范

## Final direction

唯一开屏方案：**B / 拓扑扫描（TOPO SCAN）**。

## Motion sequence

1. 资源完成加载后，拓扑图从模糊低透明度恢复清晰。
2. 两层校准圆环从中心扩散，分别延迟 80ms 与 180ms。
3. 黄色扫描线在 1.1 秒内从顶部扫到底部。
4. 用户点击进入后，黄色水平扫描带扩展至全屏并切入工程总览。

## Boundaries

- 旧对比方案的组件状态、控制台、查询入口和关键帧均已删除。
- 正常启动页始终使用 `boot-motion-scan`。
- `prefers-reduced-motion: reduce` 下取消扫描、圆环和擦除动画，并缩短进入等待。

## Verification

- 加载未完成时进入按钮不可操作。
- 加载完成后扫描线、双圆环与拓扑图动画均存在。
- 点击“进入工作台”后进入 `data-section="overview"`。
- 构建、静态测试和浏览器运行日志通过。
