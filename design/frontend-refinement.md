# 前端视觉精修计划

## 设计对象

- 主题：面向嵌入式、机械设计、3D 打印、工程竞赛与无人机研究的个人工程研发控制台。
- 使用者：需要在学习、方案、项目和工具之间高频切换的工科学生。
- 页面唯一任务：让使用者在进入工作台后立即看清当前行动，并能沿同一套工程信息语言进入任一模块。

## 视觉 Token

只使用六个主色，其他状态色只能作为数据状态出现，不能成为装饰色。

- `Field Black / #0B0F0E`：深色工作区和控制台底材。
- `Carbon / #17201C`：抬升面板、顶部框架和主要文字。
- `Paper / #F2F4EF`：浅色卡片与阅读面。
- `Mist / #D5DBD5`：总览、计划和日历的工程图纸底色。
- `Datum / #8E9992`：刻度、边线、次级文字。
- `Signal Yellow / #FFF44F`：当前状态、进度与唯一主行动。

## 字体角色

- 展示字体：`NovecentoWorkbench`，只用于大标题、模块编号和关键数据；宽体字形负责“设备铭牌”气质。
- 正文字体：`HarmonyWorkbench`，用于中文标题、正文、按钮与表单，保证密集界面的可读性。
- 数据字体：`SpaceWorkbench`，用于时间、百分比、ID、英文眉题、状态和刻度，开启等宽数字。

基础层级：页面标题 `clamp(36px, 4vw, 58px)`；模块标题 `24–30px`；卡片关键数据 `42–52px`；正文 `12–14px`；按钮 `12px`；数据与眉题 `9–11px`。不再出现 6–8px 的关键说明文字。

## 布局策略

```text
┌── 84 ──┬──────────────────────── 顶部状态条 ───────────────────────┐
│  W /   │ 当前栏目 + 一句作用说明        LOCAL / DATE / SETTINGS  │
├────────┼───────────────────────────────────────────────────────────┤
│ 01–06  │  00 ─────────────── 工程测绘标尺 ─────────────── 100     │
│ 固定轴 │  ┌──────── 任务宣言 / 主操作 ────────┬── FIELD 00 ──┐   │
│        │  └────────────────────────────────────┴──────────────┘   │
│        │  ┌──── 今日：主卡 ────┐ ┌─项目─┐ ┌─知识输入─┐          │
│        │  └────────────────────┘ └──────┘ └──────────┘          │
└────────┴───────────────────────────────────────────────────────────┘
```

- 左侧导航是固定工程坐标轴，编号对应六个真实模块，保留但降低装饰感。
- 总览由“今日行动”承担主视觉，项目和知识输入作为并列次级信号；不再三卡完全等权。
- 各模块共享相同的顶部基准线、标题高度、卡片边线和数据字号，深浅主题只改变底材，不改变结构。
- 桌面端提高横向利用率并压缩无意义留白；窄屏保留左轴，内容按单列重排。

## Signature：工程测绘标尺

在内容区顶部和关键进度上使用带主刻度、次刻度、坐标标签与当前点位的标尺。它不是装饰编号：总览标尺表达当天完成度，栏目标题标尺表达当前模块位置，进度条表达任务完成值。黄色只标记当前读数或可执行主操作。

## 自我检查与修订

黑底与黄色是参考项目已经明确的视觉约束，不能为了规避常见风格而擅自改变。为避免落入“通用深色 Dashboard + 荧光强调色”的模板，本轮不增加渐变统计卡、圆角胶囊、玻璃拟态或无意义大数字；用工程坐标轴、可读的测绘刻度、切角和真实进度值建立只属于工程研发工作台的结构语言。大胆之处只放在标尺系统，其余材质保持克制。

## 实施与验收

- 已实现六段栏目坐标标尺、进度刻度和左侧固定工程轴。
- 总览改为 `6 / 3 / 3` 非对称栅格，今日行动成为主卡；在 1400px 以下自动退化为 `6 / 6 / 12`，720px 下为单列。
- 六个栏目统一为 78px 标题区、9px 以上系统标签和 12px 以上主要控制文本；关键中文标题为 20–58px。
- 已检查 1723px 桌面、768×900 和 720×900；没有页面级横向溢出。
- 构建与 2 项渲染测试通过；Lint 0 错误，仅保留两条原有启动图片性能提示。
